# 二手手机 AI 租赁门店经营后台原型

面向二手手机门店的可点击 PC 后台原型，覆盖闲鱼多店管理、集中 IM、AI 接待设置、平台运营后台、二手手机商品与设备档案、手机使用方案、订单履约和经营数据。

## 在线访问

GitHub Pages 部署完成后，可通过仓库的 Pages 地址直接访问。

## 核心演示链路

1. 工作台查看高意向线索与今日待办。
2. IM 聊天中查看 AI 意图判断、风险提示和推荐方案。
3. 切换人工接待、使用 AI 建议回复或发起虚拟电话提醒。
4. 点击“给客户出方案”，生成买、租、修、换、旧机抵扣对比方案并预约到店。
5. 在二手手机模块切换商品列表、设备档案、待补充知识和上下架任务。
6. 生成闲鱼营销素材，审阅商品图、标题、描述、价格、售后和租赁说明。
7. 通过发布前置校验后，再加入闲鱼自动上架任务。
8. 在 AI 接待设置中确认门店只能改业务事实，高风险规则由平台锁定。
9. 切换到平台运营后台，查看策略模板、模型参数、强制规则、审计日志和异常复盘。
10. 在订单与经营数据中查看租赁、买断、续租、换机等生命周期数据。

这是交互原型，页面数据为演示数据，不连接真实闲鱼账号和交易接口。
