# 二手手机 AI 租赁门店经营后台原型

面向二手手机门店的可点击 PC 后台原型，覆盖闲鱼多店管理、集中 IM、AI 客服、二手手机商品与设备档案、租赁方案、订单履约和经营数据。

## 在线访问

GitHub Pages 部署完成后，可通过仓库的 Pages 地址直接访问。

## 核心演示链路

1. 工作台查看高意向线索与今日待办。
2. IM 聊天中查看 AI 意图判断、风险提示和推荐方案。
3. 切换人工接待、使用 AI 建议回复或发起虚拟电话提醒。
4. 生成租赁方案并预约到店。
5. 在二手手机列表中查看商品、设备档案、租价和 AI 知识关联。
6. 在订单与经营数据中查看租赁、买断、续租、换机等生命周期数据。

这是交互原型，页面数据为演示数据，不连接真实闲鱼账号和交易接口。
